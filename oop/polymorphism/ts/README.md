# TypeScript
The application of Polymorphism in TypeScript is achieved through an interface or method to work with different data types.  

The three mains types are:  
1. Subtype: A parent class or interface defines a shape, and multiple child classes implement it with their own unique behaviors.
2. Parametric: Allows you to write abstract, reusable functions, interfaces, or classes that accept types as parameters. It provides ultimate type safety without locking your functions or components into a single static type. 
3. Ad Hoc: A single function or operator behaves differently depending on the types of its arguments through function overloading.
