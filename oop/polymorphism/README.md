# Polymorphism
## Definition
Polymorphism is a concept that allows different object to respond to the same method but in their own way. So something of a super class.

## What It Solves
Writing less excessive and rigid (if-else) or switch statements when dealing with related object ypes.

## When To Use It
When you want to reduce the amount of conditional statements for related data types.

## Pros
- Promotes loose coupling by making sure that not everything needs to be known about a single class.
- Code reusability by writing generic code that work broadly with base classes.

## Cons
- It may result in readibility issues but this might be more to do with the developer.

## Real World Example
An example of polymorphism in the real world is a Universal TV Remote. When you press the Power button, you issue a single command. However, the exact behavior changes dynamically based on which device is linked: the TV turns on, the sound system mutes, or the gaming console powers up.
