# Inheritance
## Definition
Inheritance is a concept that allows one class to inherit the properties and methods from another class.

## What It Solves
Continuing to always reuse your code and make it modular.

## When To Use It
When you want both modular code and hierachy. 

## Pros
- Code reusability. 
- Extensibility by introducing new functionalities to a subclass.

## Cons
- Can be fragile if not done carefully if it were to make assumptions for sub classes.

## Real World Example
An example of Inheritance in the real world is a Vehicle as a base class and the sub classes being a Car, Motorbike and Truck.
