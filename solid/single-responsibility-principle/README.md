# Single Responsibility Principle
## Definition
Single Responsilbilty Principles is a concept that involves making sure that class should have one and only one reason to change. Meaning it should have a single purpose of responsiblity.

## What It Solves
It solves issue of combining different roles that a class might have when really they should have one.

## Pros
- Easier maintainability since you are now working with one responsibility for the class
- Easier testing and debugging since it is now straightforward

## Cons
- Can risk overengineering if you create classes that are confusing

## Real World Example
Imagine a baker who is responsible for baking bread. The baker's role is to focus on the task of baking bread, ensuring that the bread is of high quality, properly baked, and meets the bakery's standards.
